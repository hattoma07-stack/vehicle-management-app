# 車両管理アプリ

事業所・車種・ナンバー・所有者名義・購入年月日・車検・リース満了日・タイヤサイズを一元管理するアプリです。
フロントエンドは `index.html` 単体（ビルド不要）、バックエンドはGoogleスプレッドシート（Google Apps Script経由）です。
同じ接続設定（URLと合言葉）を使えば、複数の端末・複数の職員で同じデータをリアルタイムに共有できます。

## セットアップ手順

### 1. スプレッドシートとApps Scriptを用意する

1. 新しいGoogleスプレッドシートを作成する（名前は自由）
2. メニューの「拡張機能」→「Apps Script」を開く
3. デフォルトの `Code.gs` の中身を全部消して、このフォルダの [`GoogleAppsScript_Code.gs`](GoogleAppsScript_Code.gs) の中身を丸ごと貼り付ける
4. スクリプト内の `API_TOKEN` の値を、他人に推測されない適当な文字列に書き換える（例: パスワード生成ツールで作った30文字程度のランダム文字列）
5. 保存する（Ctrl+S / Cmd+S）

### 2. ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択で「ウェブアプリ」を選ぶ
3. 「実行するユーザー」＝自分（Me）
4. 「アクセスできるユーザー」＝
   - 組織のGoogle Workspaceがあれば「〇〇（組織名）内の全員」
   - まだ無ければ、暫定的に「全員」（URLと合言葉を知っている人だけがアクセスできる状態になります）
5. 「デプロイ」を押すとアクセス許可の確認が出るので許可する
6. 表示される「ウェブアプリのURL」（`.../exec` で終わるもの）を控えておく

### 3. 初期データを投入する（任意）

以前のExcel台帳から移行した21台分のデータを最初から入れておきたい場合：

1. Apps Scriptエディタの関数選択プルダウンで `seedIfEmpty` を選ぶ
2. 実行ボタン（▶）を押す（初回は権限承認が必要）
3. 車両シートが空のときだけ21台が自動投入されます（既にデータがあれば何もしません）

### 4. アプリ側で接続設定をする（管理者のみ）

接続設定の画面は、事務職員の混乱を避けるため通常のURLでは表示されません。
**URLの末尾に `?admin=1` を付けたとき（管理者用URL）だけ**表示されます。

1. `index.html?admin=1` をブラウザで開く（ローカルファイルをダブルクリックする場合はアドレスバーで `?admin=1` を追記、公開後のURLなら `https://.../?admin=1`）
2. 右上に表示される「⚙ 接続設定」から、手順2で控えたウェブアプリURLと、手順1で決めた合言葉（API_TOKEN）を入力して保存
3. 保存すると自動でスプレッドシートからデータを読み込みます

この接続設定は**その端末のブラウザ（localStorage）にのみ**保存されます。事務職員に配布するURLには `?admin=1` を付けないでください（付けない限り、接続設定・同期状況などの管理者向け表示は一切出てきません）。新しい端末で使い始めるときは、管理者がその端末で一度だけ `?admin=1` 付きURLを開いて設定すれば、以後その端末は通常URLのブックマークだけで使えます。

## 日常の使い方（事務職員向け）

- はじめて開いたときだけ「お名前」の入力を求められます（変更履歴に記録するためのものです）。一度入力すればその端末では次回から表示されません
- 一覧表は閲覧専用です。内容の追加・変更は、行の「✎ 編集」ボタン（新規追加は「＋ 車両を追加」）からフォームを開いて行います
- 🗑ボタンで削除、▲▼ボタンで並び替え
- 「事業所を追加」で車両がまだ無い事業所も先に登録できます
- 他の人が編集した内容は、起動時やこの画面に戻ってきたとき（別タブ・別アプリから切り替えたとき）に自動で最新化されます
- 「データ出力 (JSON)」「CSV出力」は、その時点の内容を手元にバックアップとして保存するためのものです

## 変更履歴の確認（管理者向け）

追加・編集・削除・事業所の追加/削除を行うたびに、スプレッドシート内に自動作成される **「History」シート**に、以下の内容が記録されます。

| 列 | 内容 |
|---|---|
| 日時 | 操作が行われた日時 |
| 操作 | 追加・編集・削除・事業所追加・事業所削除 |
| 担当者 | 操作した人が初回起動時に入力した名前（自己申告。Googleログインによる本人確認ではありません） |
| 端末 | 操作した人のブラウザ・OSの種類（例: Chrome / Mac） |
| 対象 | どの車両（事業所・車種・ナンバー）または事業所への操作か |
| 詳細 | 編集の場合、変更されたフィールドの「旧値→新値」 |

管理者はGoogleスプレッドシートを直接開いて「History」シートを見るだけで、いつ・誰が・何を変更したかを確認できます（アプリ側に履歴閲覧画面は用意していません）。

## コードを更新した場合の再デプロイ

`GoogleAppsScript_Code.gs` を編集して保存しただけでは、公開中のURLには反映されません。
「デプロイ」→「デプロイを管理」→ 編集（鉛筆アイコン）→ バージョン「新しいバージョン」を選んで「デプロイ」を押してください（URLは変わりません）。

## 複数人での同時利用について

書き込み処理はすべてスクリプト側でロックしてから行うため、複数人が同時に編集しても行が壊れたり重複したりしません。
ただし全員が同じ行を同時に編集した場合は、後から保存した内容が残ります。
