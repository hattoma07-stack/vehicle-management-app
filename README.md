# 車両管理アプリ

事業所・車種・ナンバー・所有者名義・購入年月日・車検・リース満了日・タイヤサイズを一元管理するアプリです。
フロントエンドは `index.html` 単体（ビルド不要）、バックエンドはGoogleスプレッドシート（Google Apps Script経由）です。
同じ接続設定（URLと合言葉）を使えば、複数の端末・複数の職員で同じデータをリアルタイムに共有できます。

## セットアップ手順

### 1. スプレッドシートとApps Scriptを用意する

1. 新しいGoogleスプレッドシートを作成する（名前は自由）
2. メニューの「拡張機能」→「Apps Script」を開く
3. デフォルトの `Code.gs` の中身を全部消して、このフォルダの [`GoogleAppsScript_Code.gs`](GoogleAppsScript_Code.gs) の中身を丸ごと貼り付ける
4. スクリプト内の `API_TOKEN` の値を、他人に推測されない適当な文字列に書き換える（例: パスワード生成ツールで作った30文字程度のランダム文字列）
5. 保存する（Ctrl+S / Cmd+S）

### 2. ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択で「ウェブアプリ」を選ぶ
3. 「実行するユーザー」＝自分（Me）
4. 「アクセスできるユーザー」＝
   - 組織のGoogle Workspaceがあれば「〇〇（組織名）内の全員」
   - まだ無ければ、暫定的に「全員」（URLと合言葉を知っている人だけがアクセスできる状態になります）
5. 「デプロイ」を押すとアクセス許可の確認が出るので許可する
6. 表示される「ウェブアプリのURL」（`.../exec` で終わるもの）を控えておく

### 3. 初期データを投入する（任意）

以前のExcel台帳から移行した21台分のデータを最初から入れておきたい場合：

1. Apps Scriptエディタの関数選択プルダウンで `seedIfEmpty` を選ぶ
2. 実行ボタン（▶）を押す（初回は権限承認が必要）
3. 車両シートが空のときだけ21台が自動投入されます（既にデータがあれば何もしません）

### 4. アプリ側で接続設定をする

1. `index.html` をブラウザで開く（ダブルクリックでOK。サーバー不要）
2. 右上の「⚙ 接続設定」から、手順2で控えたウェブアプリURLと、手順1で決めた合言葉（API_TOKEN）を入力して保存
3. 保存すると自動でスプレッドシートからデータを読み込みます

この接続設定はブラウザ（localStorage）に保存されるため、他の端末でも同じURLと合言葉を入力すれば同じデータにアクセスできます。

## 日常の使い方

- 表の各セルをクリックすると直接編集でき、セルを離れると自動的にスプレッドシートへ保存されます
- ＋ボタンで行を追加、🗑ボタンで削除、▲▼ボタンで並び替え
- 「事業所を追加」で車両がまだ無い事業所も先に登録できます
- 「🔄 再読み込み」で、他の人が編集した最新の内容を取り込めます
- 「データ出力 (JSON)」「CSV出力」は、その時点の内容を手元にバックアップとして保存するためのものです

## コードを更新した場合の再デプロイ

`GoogleAppsScript_Code.gs` を編集して保存しただけでは、公開中のURLには反映されません。
「デプロイ」→「デプロイを管理」→ 編集（鉛筆アイコン）→ バージョン「新しいバージョン」を選んで「デプロイ」を押してください（URLは変わりません）。

## 複数人での同時利用について

書き込み処理はすべてスクリプト側でロックしてから行うため、複数人が同時に編集しても行が壊れたり重複したりしません。
ただし全員が同じ行を同時に編集した場合は、後から保存した内容が残ります。

## 今後の拡張候補

- 組織のGoogleアカウントが決まったら、`ALLOWED_EMAILS` に列挙してアクセスを絞る
- 将来的にクラウド上で常時稼働させたい場合は、この構成（Apps Script + スプレッドシート）のままでも、GitHub Pages等に `index.html` を置いて公開する形でそのまま運用できます
